# Technical Design: Telegram Bot Architecture

## 1. Data Ingestion (Telegram Webhook)
The system uses an **Installable Webhook** via Google Apps Script's `doPost(e)` function.

### Webhook Flow
1.  **Incoming:** Telegram sends a JSON payload to the GAS Web App URL.
2.  **Security:** The script validates the `from.id` against a hardcoded `ALLOWED_USER_ID`.
3.  **Routing:**
    *   **Text Message:** Parsed as a manual `rawKwh` entry.
    *   **Photo Message:** Triggers the OCR pipeline.

---

## 2. OCR Pipeline
1.  **Fetch:** The script uses `getFile` and `downloadFile` from the Telegram Bot API.
2.  **Storage:** The image blob is saved to a specific Google Drive folder.
3.  **OCR:** The file is inserted into Google Drive with the `{ocr: true}` parameter, converting it to a temporary Google Doc.
4.  **Extraction:** Regex `\b\d{1,7}(\.\d+)?\b` extracts the kWh digits.
5.  **Cleanup:** Temporary Google Docs are deleted immediately after extraction.

---

## 3. Spreadsheet Schema (`Readings`)
| Col | Name | Type | Description |
| :--- | :--- | :--- | :--- |
| **A** | `Timestamp` | `Date` | Generated by the script on ingestion. |
| **B** | `Raw_kwh` | `Number` | Manual entry or OCR result. |
| **C** | `Image_Url` | `URL` | Link to the archived meter photo in Drive. |
| **D** | `Shift` | `String` | Day, Night, Manual, or Gap. |
| **E** | `Delta_kwh` | `Number` | Consumption since previous row. |
| **F** | `Daily_Total`| `Number` | 24h total (calculated on AM readings). |
| **G** | `Notes` | `String` | Anomaly flags and gap details. |

---

## 4. Logic & Localization
- **Timezone:** `Asia/Manila` (UTC+8).
- **Shift Windows:**
    - **AM (6-10 AM):** Closes the "Night" shift.
    - **PM (6-10 PM):** Closes the "Day" shift.
- **Gap Detection:** If `hoursElapsed > 14`, the shift is labeled as a "Gap".
